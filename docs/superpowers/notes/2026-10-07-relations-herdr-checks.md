# v0.1.2 관계 보기 herdr 확인 결과

날짜: 2026-10-08 · herdr 0.9.3 · macOS · 브랜치 `feat/issue-relations` (17e16e0)

## 방법

- `scripts/deploy-local.sh`로 이 기기에 배포했다(`jh.linear` 0.1.2).
- 실제 워크스페이스에서 확인용 이슈 두 개를 골랐다. 읽기 전용 쿼리로 식별자만 뽑았다.
  - 막는 이슈가 있는 진행 중 이슈 하나
  - 하위 이슈가 12개인 상위 이슈 하나
- 이 문서에는 이슈 제목, 사람 이름, 식별자를 남기지 않는다.

## 결과

1~7은 사용자가 herdr 팔레트에서 확인했다. 8~9는 배포한 CLI를 직접 실행해 확인했다.

| # | 항목 | 결과 |
|---|---|---|
| 1 | 막힌 이슈 상세: URL 아래 관계 칸, `막힘` 빨강, `상위` 흐리게 | 통과 |
| 2 | 하위가 많은 상위 이슈: `하위    12개 중 11개 남음`, 끝난 하위 줄만 흐리게 | 통과 |
| 3 | `t` 관계 메뉴: 상세와 같은 색, 글자로 거르기, Enter로 열기 | 통과 |
| 4 | Esc 여러 번: 한 단계씩 돌아가고 스크롤 위치 유지, 마지막에 목록 | 통과 |
| 5 | 관계 줄 클릭(스크롤한 뒤 포함) | 통과 |
| 6 | 한글 입력 상태의 `ㅅ` | 통과 |
| 7 | 관계 없는 이슈: 관계 칸 없음, `t` 메뉴 제목 "관계 없음" | 통과 |
| 8 | CLI `show`: URL 다음 관계 칸, 머리 줄에서 `상위` 빠짐, 하위 요약과 Linear 하위 순서 | 통과 |
| 9 | 오프라인 `show`(`HTTPS_PROXY=http://127.0.0.1:9`): 오프라인 안내와 캐시된 관계 | 통과 |

## 남은 것

문서 손질 몫이다. 동작에는 영향이 없다.
- 관계 스펙 2.3·5장의 "관계를 불러오지 못했어요" 조건 문구가 실제보다 넓게 읽힌다. 관계 없이 다시 받았어도 아는 관계가 있으면 그 관계를 보여 준다.
- 관계 스펙 8장의 시제, 7장 테스트 목록에 CLI 대체 표시·브랜치 찾기 테스트가 빠져 있다.
