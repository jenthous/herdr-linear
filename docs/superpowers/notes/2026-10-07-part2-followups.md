# 2부 최종 리뷰 후속 항목

2부(팔레트 TUI + herdr 연결) 최종 리뷰 결과는 Critical 0건, Important 5건, Minor 14건이었다. Important 5건은 모두 고쳤다(커밋 0dbbfd7). 아래는 3부로 넘기는 것들이다. 3부 계획을 쓸 때 입력으로 쓴다.

## 고친 것 (참고)

| 항목 | 내용 | 테스트 |
|---|---|---|
| I1 | 검색 모드에서 Tab으로 탭을 바꾸면 목록 모드가 되어, 이어서 친 글자가 `r`·`o`·`y`·`q` 동작으로 실행됨 → 탭 전환은 모드를 바꾸지 않음 | `tab_switch_keeps_the_mode_so_typing_still_searches` |
| I2 | 검색어를 바꿨는데 새 요청이 나가기 전에 도착한 이전 검색어의 응답이 새 목록에 섞임 → 검색어가 바뀔 때마다 순번을 올림 | `response_for_an_edited_query_is_ignored` |
| I3 | 캐시에 없는 이슈가 없음·보관이거나 요청이 실패해도 "불러오는 중…"이 계속 보임 → "찾을 수 없거나 보관·삭제된 이슈예요" / "불러오지 못했어요" | `detail_without_cache_shows_gone_or_failure` |
| I4 | 키를 바꾼 첫 실행에서 워크스페이스 확인(viewer)이 오프라인 등으로 실패하면, 다른 워크스페이스 캐시를 보이고 새 결과와 섞음 → 확인 전에는 계속 미루고 다음 요청 때 다시 확인 | `unverified_workspace_stays_hidden_when_viewer_fails` |
| I5 | 팔레트 머리 정보에 예상치·마감일이 없음(스펙 4.6) | `header_shows_estimate_and_due_date` |

## 2부 뒤에 더한 것 (사용자 피드백)

- 복사 기본을 티켓 URL로 바꿨다(`y`). `Y`는 열린 PR 링크를 복사하고, ID 복사는 Ctrl+K 메뉴로 옮겼다. 상세 머리에 열린 PR을 표시한다(968a22d).
- 마우스를 지원한다(e4d2ce5).
  - 휠로 목록을 움직이고 상세를 스크롤한다.
  - 줄 클릭은 선택, 선택된 줄을 다시 클릭하면 상세다.
  - 탭·메뉴 항목은 클릭하면 바로 실행된다.
- 사용자는 herdr에 주로 원격으로 붙는다.
  - `o`(브라우저 열기)는 herdr가 도는 기기에서 열린다. 사용자는 안 써도 괜찮다고 했다.
  - 복사(OSC 52)는 원격에서도 동작한다.

## 3부 계획 작성 시 주의

- 세는 요청(`loading`)과 그 끝맺음은 1:1이어야 한다. 새 Effect·Msg를 더할 때마다 실패 경로까지 맞춘다. 리뷰에서 이 회계는 맞았다.
- 순번·카운터 같은 내부 값을 테스트에 하드코딩하지 않는다. 요청에서 읽어서 쓴다(I2를 고칠 때 이렇게 바꿈).
- 사이드 패널은 오래 돈다. N2, N6, N10, N11은 사이드 패널에서 더 자주 보일 것이다.
